Status/Public API/Incident #42

Post-mortem #42· Resolved

Public API was down for 41 minutes

Thursday 18 September 2026, 19:12 to 19:53 UTC. Web app and Mobile sync were down with it.

Download .mdPublic API's history

What happened

At 19:12 the API stopped answering: every request waited for a database connection that never came. A nightly export had opened connections without closing them, and the pool (100 connections) filled up.

We restarted the export worker at 19:49; the API answered again at 19:53. No data was lost. Requests made during the outage failed with an error and can be retried.

What we changed

The export now uses its own pool of 10 connections, and Hora watches the pool: it says "slow" at 80 %, long before it is full.
